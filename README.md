# Nemischa 0 dan

O‘zbek tilida nemis tilini A1 dan C2 gacha o‘rgatuvchi Expo ilova.

## Imkoniyatlar

- 6 ta CEFR daraja va 24 ta kurs moduli
- 3 000 ta so‘z va foydali birikma, tarjima hamda kontekstli misollar
- Har bir modulda 12 ta faol lug‘at birligi va tarjimali namunalar
- 24 ta mavzuli grammatika darsi: qoida, qolip, audio misol va eslatmalar
- 48 ta izohli grammatik savol hamda daraja bo‘yicha alohida testlar
- Qurilmaning nemischa ovozi bilan normal va sekin talaffuz
- Ma’no, teskari tarjima, tinglash, yozish, artikl va kontekst mashqlari
- Lug‘at qidiruvi, sevimlilar va o‘zlashtirilgan so‘zlar
- Lokal saqlanadigan XP, aniqlik va kurs progressi

## Ishga tushirish

Node.js 20.19 yoki yangirog‘ini o‘rnating, so‘ng:

```bash
npm install
npm run start
```

Terminaldagi QR kodni Expo Go orqali skanerlang yoki `w` tugmasi bilan web versiyasini oching.
